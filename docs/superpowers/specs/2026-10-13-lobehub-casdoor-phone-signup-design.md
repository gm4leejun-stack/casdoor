# LobeHub 使用 Casdoor 手机号注册设计

状态：已确认，按最低成本实现

日期：2026-10-13

## 1. 目标

LobeHub 继续使用现有 Casdoor OAuth/OIDC 登录。在 Casdoor 页面开放新用户注册：

- 登录默认使用中国大陆手机号和短信验证码；
- 登录页保留用户名密码入口，所有已有用户名密码的正常账号均可使用；
- 注册只允许中国大陆手机号和短信验证码；
- 隐藏邮箱、微信、GitHub 等其他登录和注册方式；
- 使用现有 BeiBei AI 品牌、用户协议和隐私政策。

不修改 LobeHub 代码。LobeHub 保留独立 Application，并与 Gundam-Agent 共用现有 Casdoor 服务、`beibei` Organization 和用户目录。Casdoor 继续使用稳定的用户 ID 作为 OIDC `sub`。

## 2. 最小实现

### 2.1 只做配置的部分

在 LobeHub 和 Gundam-Agent 对应 Application 中统一配置：

1. 登录方式第一项为 `Verification code / Phone only`，第二项为 `Password`，从而默认显示手机验证码并可切换到用户名密码。
2. 隐藏邮箱验证码、微信、GitHub 等其他登录方式。
3. 注册项只显示 Phone、Agreement 和 Signup button；Phone 必须验证，Agreement 必须勾选。
4. 隐藏 Username、Password、Email、Providers、昵称和头像等其他注册项。
5. 使用现有短信 Provider、验证码有效期、重发间隔和 CAPTCHA 配置。
6. LobeHub Application 保留独立 Client ID、Client Secret 和回调地址，并设为可信应用，注册或登录后直接返回 LobeHub。
7. 页面品牌、Logo、favicon、用户协议和隐私政策直接使用现有 BeiBei AI 数据库配置，不在代码中硬编码品牌。

### 2.2 仅补现有配置无法实现的代码

只做以下必要修改：

1. 手机验证码登录和手机号注册页面固定为 `CN / +86`，不显示国家/地区切换。后端同时拒绝非 `+86` 的该流程请求，避免只靠前端隐藏。
2. 未勾选协议时不能获取注册验证码，也不能提交注册。
3. 获取注册验证码时不再返回“Phone already exists”。格式合法的手机号使用中性响应，不从响应暴露是否已注册。
4. 已注册的正常手机号在注册页验证成功后直接登录原账号并继续原 OAuth/OIDC 流程；禁用账号统一提示“账号暂不可用，请联系客服”，不创建新账号。
5. 新用户由 Casdoor 生成内部 Username，并将 DisplayName 设置为脱敏手机号，例如 `用户 138****1234`；不要求填写昵称或头像。

OAuth 请求原有的 `client_id`、`redirect_uri`、`state`、`scope`、`nonce` 和 PKCE 参数继续沿用 Casdoor 现有流程。手机号换绑不改变 Casdoor 用户 ID 和 OIDC `sub`。

## 3. 沿用现有能力

- 沿用 Casdoor 现有手机号校验、验证码有效期、成功后失效、重发间隔、输错冻结和 CAPTCHA。
- 沿用 Casdoor 现有用户唯一性和创建逻辑，不新增数据库表、唯一索引、事务框架或数据迁移。
- 沿用现有会话，上线时不强制用户退出。
- 不迁移或补绑存量账号；有有效用户名密码的存量用户继续通过密码入口登录。
- 本期不提供自助换绑手机号或注销，由客服按现有流程处理。

## 4. 明确不做

- 不新增 Redis、队列、短信风控服务、设备指纹、设备农场识别或小时/每日发送限额。
- 不改造账号体系、OAuth/OIDC 架构或 LobeHub 用户映射。
- 不部署第二套 Casdoor，不建设身份桥接或用户同步。
- 不做与本注册流程无关的通用重构。

## 5. 验收

- [ ] 登录页默认是固定 `+86` 手机验证码，可切换到用户名密码。
- [ ] 管理员和普通存量用户均可使用有效用户名密码登录。
- [ ] 注册页只显示手机号、验证码、协议和注册按钮，未勾选协议不能获取验证码或注册。
- [ ] 新手机号注册后自动返回 LobeHub，LobeHub 能按稳定 `sub` 建立账号。
- [ ] 已注册手机号从注册页验证后登录原账号，不创建重复用户。
- [ ] 获取验证码阶段不提示手机号是否已注册；禁用账号验证后被拒绝。
- [ ] 邮箱和第三方登录、注册入口均不可见，非 `+86` 请求不能绕过后端校验。
- [ ] 页面展示现有 BeiBei AI 品牌以及有效的用户协议和隐私政策。
- [ ] 现有验证码重发、过期、输错冻结和 CAPTCHA 继续生效。
- [ ] LobeHub 和 Gundam-Agent 登录回归正常，已有会话不受影响。
